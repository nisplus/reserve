## 1. ログインと画面の見かた

### ログイン

管理画面の URL は **`（サイトのURL）/admin`** です。ユーザー名とパスワードを入力してください。

- パスワードは**システムが発行したもの**です。ご自身で変更する画面はありません。分からなくなった場合は、別の事務局アカウントから「パスワード再発行」を行ってください（→ [8. アカウントの管理](#8-アカウントの管理)）。
- **パスワードを 10 回続けて間違えると、そのアカウントは 15 分間ログインできなくなります。** 15 分待つか、別の事務局アカウントからパスワードを再発行してください。
- **30 分何も操作しないと自動的にログアウト**します。また、ログインから **8 時間**経つと、操作中でもログアウトします（長時間の作業中は、こまめに保存してください）。

### メニュー

| メニュー | 内容 |
|---|---|
| ダッシュボード | 全体の件数と、繰り上げ候補のある開催回 |
| 予約一覧 | 申込者の検索・CSV 出力・繰り上げ・キャンセル |
| 体験内容 | 体験プログラムと開催回の登録・編集 |
| 一斉送信 | 申込者へのお知らせメール |
| 会社 | 開催企業の登録・編集（事務局のみ） |
| メール | メール送信キュー（事務局のみ） |
| アカウント | 管理画面のアカウント発行（事務局のみ） |
| 受付設定 | 予約受付全体の開始・停止（事務局のみ） |
| 公開サイト | 申込者から見える画面を別タブで開きます |

「会社」「メール」「アカウント」「受付設定」は事務局だけのメニューです。会社担当者の画面には表示されず、URL を直接入力しても開けません。

### ダッシュボード

上段が申込の状況（確定予約 / キャンセル待ち / 満席の開催回 / 繰り上げ候補あり）、下段が登録の状況（会社 / 体験内容 / 開催回 / メール未送信）です。
**「メール未送信」に「（失敗 N）」と付いたら、メールが送れていません。**「メール」メニューで確認してください（→ [7. メールの管理](#7-メールの管理)）。

## 2. 開催までの準備

登録は **会社 → 体験内容 → 開催回** の順です。上から順に作らないと選択肢に出てきません。

### 2-1. 会社を登録する

「会社」→「会社を登録」。

| 項目 | 説明 |
|---|---|
| 会社名 | 公開側にそのまま表示されます |
| 会社名（かな） | 並び替え・検索用。省略できます |
| エリア | 未設定、または設定された区域（`config.php` の `areas`）。**未設定の会社は、公開側のエリア絞り込みに出てきません** |
| 表示順 | 小さいほど上に表示されます |
| 公開する | チェックを外すと、その会社の体験プログラムはすべて公開側から消えます |

### 2-2. 体験内容（体験プログラム）を登録する

「体験内容」→「体験プログラムを登録」。

| 項目 | 説明 |
|---|---|
| 主催会社 | 先に会社を登録しておいてください |
| 体験プログラム名 | 公開側とメールの件名に使われます |
| 説明 | 改行は反映されます。HTML は使えません |
| 会場 | 受付場所・集合場所など |
| 表示順 | 小さいほど上 |
| 公開する | **会社も公開になっていないと公開側に出ません**（両方が公開で初めて表示されます） |
| 1予約あたりの上限人数 | 1 件の予約で申し込める人数の上限（既定 20 名） |
| 対象年齢の下限・上限 | **両方とも空欄で構いません。片方だけの設定もできます。** 0 と空欄は別の意味です（0 は「0 歳以上」、空欄は「下限なし」） |
| 付き添いの保護者も参加人数に含める | 下記参照 |
| 予約不要 | 下記参照 |
| 外部リンクURL | 開催企業の紹介ページなど。`https://` から入力してください。空欄なら表示されません |

#### 「付き添いの保護者も参加人数に含める」の使い分け

- **チェックする** … 親子で一緒に体験するなど、**来場する全員が参加者**の場合。定員＝来場人数になります。
- **チェックしない** … 体験するのは子どもだけで、保護者は見学する場合。予約画面に「付き添いの人数」欄が出ます。
  **付き添いの方は定員を消費しません。** 会場の収容人数を確認するときは、予約一覧と CSV の「来場人数」（参加人数＋付き添い）をご覧ください。

#### 「予約不要」

チェックすると**予約ボタンが出なくなります**が、**開催時間は時間割として公開側に表示され続けます**。
「申込は要りませんが、この時間にやっています」とお知らせしたいときに使ってください。あとでチェックを外せば、同じ開催回のまま受付が始まります。

#### 対象年齢について

予約時に入力された**すべての方の年齢**を確認し、**1 人でも範囲外なら受け付けません**（キャンセル待ちにもなりません）。
なお、**すでに受け付けた予約は、あとから年齢の範囲を変えても取り消されません。**

### 2-3. 開催回を作る

「体験内容」の一覧から、対象の行の「開催回」を開きます。

**1 件ずつ作る場合**（「**1件だけ作成**」）

| 項目 | 説明 |
|---|---|
| 開始日時・終了日時 | 日本時間 |
| 定員（人数） | **人数単位です**（3 名で申し込まれたら 3 席消費します） |
| 受付状態 | 受付中／受付終了。**受付終了にすると公開側から消えます。既存の予約はそのまま残ります** |

**まとめて作る場合**（「**まとめて作成**」）

初回の開始日時、所要時間（分）、間隔（分）、回数、定員を入力すると、等間隔の開催回をまとめて作ります。
「間隔」は前の回の終了から次の回の開始までの休憩時間です。0 にすると隙間なく連続します。

### 2-4. 削除について

安全のため、次の場合は削除できません。メッセージでご案内します。

- **予約履歴のある開催回** … 削除できません。受付を止めたいだけなら「受付終了」に変更してください。
- **開催回が残っている体験プログラム** … 先に開催回を削除してください。
- **体験プログラムや担当者アカウントが残っている会社** … 先にそちらを削除してください。

## 3. 公開と受付の開始

公開側に表示されるのは、**会社が公開 かつ 体験プログラムが公開 かつ 開催回が受付中**のものです。

さらに全体のスイッチとして「**受付設定**」があります（事務局のみ）。

| 項目 | 説明 |
|---|---|
| 予約の受付を行う | このチェックを外すと**即座に全体の受付が止まります**。日時の設定より優先されます |
| 受付開始日時 | この日時まで「ご予約の受付は◯月◯日◯時から開始します」と表示されます |
| 受付終了日時 | この日時ちょうどに受付を終了します（その時刻は含みません） |
| 停止中の案内文 | 公開側に表示する文章。空欄なら既定の文が出ます |

**受付を停止しても、体験内容・開催時間・会場は公開側に表示されたままです。止まるのは予約の受付だけです。**
また、受付停止中でも**管理画面からの繰り上げとキャンセルは行えます**。これは、受付を止める原因になった事情に対応するための操作だからです。

> 受付終了の直前に予約画面を開いていた方が、終了後に送信ボタンを押した場合も、きちんとエラーメッセージでお伝えします（席は確保されません）。

## 4. 日々の運用

### 予約一覧

「予約一覧」で、会社・体験プログラム・開催回・状態・メールアドレスで絞り込めます。

- **並び順**は 2 種類です。
  - **予約日時順** … 申込の受付順。受付状況を追うとき。
  - **会社・体験プログラム・開催日時順** … 当日の点呼や名簿づくり向け。同じ開催回の中では 確定 → キャンセル待ち → キャンセル済み の順に並びます。
- 選んだ並び順と絞り込みは、**ページ送りと CSV 出力にも引き継がれます。**
- **CSV 出力**は、絞り込んだ結果だけを出します。Excel でそのまま開けます（文字化けしません）。
  列: 予約番号／状態／開催企業／体験内容／開催日時／氏名／連絡先氏名／メールアドレス／電話番号／人数／付き添い人数／来場人数／参加者／開催企業へのメッセージ／キャンセル待ち順／予約日時／キャンセル日時

### 「氏名」と「連絡先氏名」の違い

- **氏名・参加者** … 実際に体験する方
- **連絡先氏名・メールアドレス・電話番号** … 連絡を取る相手（子どもの体験なら保護者）

**メールの宛名は「連絡先氏名」です。** 当日お呼びするのは「氏名」の方です。

### キャンセル（管理画面から）

予約一覧の「キャンセル」ボタンです。確認のポップアップが出ます。

- **この操作は取り消せません。**
- ご本人に通知メールが送られます。
- 確定していた予約をキャンセルすると席が空きますが、**その席はキャンセル待ちの方のものです**（次項）。

### 本人によるキャンセル

申込者は、予約完了メールに記載された URL から、自分で予約内容の確認とキャンセルができます。
事務局で操作する必要はありません。URL が分からなくなったという問い合わせには、予約完了メールをお探しいただくようご案内ください。
**URL を新しく発行する機能はありません。** 予約完了メールそのものが送れていない（「メール」メニューで未送信・失敗になっている）場合は、そちらを送り直せば URL も届きます。見つからないだけの場合は、予約一覧から事務局側でキャンセルして取り直していただくのが確実です。

## 5. キャンセル待ちの繰り上げ

### 空席はキャンセル待ちの方のものです

この仕組みは分かりにくいので、ぜひ覚えてください。

**キャンセル待ちの方が 1 人でもいる開催回では、席が空いていても、新しい予約はキャンセル待ちとして受け付けます。**
あとから予約した方が、先にお待ちの方を追い越さないようにするためです。

そのため、**繰り上げるまでその席は空いたままになります。** 自動では繰り上がりません。

### 繰り上げの手順

1. ダッシュボードの「**繰り上げ候補のある開催回**」を見ます。ここに出ている開催回は、空席があってお待ちの方がいる状態です。
2. 「候補を見る」から、その開催回のキャンセル待ちの方が表示されます。
3. 「**繰り上げ**」を押します。確認のポップアップが出て、ご本人に確定メールが送られます。

> **ボタンがグレーのとき**は、現在の空きではその方の人数に足りません（例: 空き 1 名に 3 名の申込）。
> その場合は、人数の収まる別の方を繰り上げるか、さらに空きが出るのを待ちます。

### 繰り上げる前に、その方の同じ日の予約を見る

予約一覧の「開催日時」の下に「**同日 他 N 件**」と出ることがあります。その方が**同じ日に予約している他の催事**です。開くと、開催企業名・体験内容・時間が並びます。

| 表示 | 意味 |
|---|---|
| **同日 他 N 件**（灰色） | 同じ日に他の予約がありますが、時間に余裕があります。**この施設の普通の使い方**ですので、気にする必要はありません |
| **⚠ 同日 他 N 件 時間が重複**（赤） | 同じ時間に別の予約があります。**繰り上げは拒否されます** |
| **⚠ 同日 他 N 件 移動時間が短い**（オレンジ） | 別の会社の催事との間隔が 15 分以下です。**繰り上げはできますが、間に合わない可能性があります** |

「繰り上げ」を押したときの確認ポップアップにも同じ内容が出ます。**オレンジの場合は、繰り上げる前にご本人に確認されることをおすすめします。**
繰り上げたあとも、画面上部のメッセージに同じ内容が残ります。

> 表示されるのは**開催企業名・体験内容・日時・状態だけ**です。他社の予約に紐づく氏名や連絡先は表示されません。

繰り上げは**事務局の判断で行う操作**です。お待ちの順番は「キャンセル待ち順」で確認できます。

## 6. 中止・延期のとき

台風などで中止・延期を決めたときの手順です。**決定は前日までに**を前提にしています。

### 手順

**① 新しい申込を止める**（必要な場合）

「受付設定」で「予約の受付を行う」のチェックを外します。特定の回だけ止める場合は、その開催回を「受付終了」に変更します。
**開催情報は表示されたままなので、「開催予定だったこと」は申込者から見えます。**

**② 申込者にお知らせする**

「一斉送信」を開きます。

| 項目 | 選びかた |
|---|---|
| 対象 | **全申込者** / **体験プログラムを指定** / **開催回を指定** |
| キャンセル待ちの方も含める | 中止・延期のお知らせなら**チェックを推奨**します（その方も予定を空けています） |
| 件名・本文 | 下記参照 |

- **1 日だけ中止**なら「**開催回を指定**」です。関係のない回の申込者に送らずに済みます。
- **キャンセル済みの方には送りません**（チェックボックスもありません）。すでに来ないと言われた方に中止の連絡をしても混乱を招くだけだからです。
- **同じメールアドレスの方は、何件ご予約されていても 1 通だけ**届きます。
- **体験内容と開催日時は本文の先頭に自動で入ります。** 受け取った方が「どの予約の話か」で迷わないようにするためです。本文には中止・延期の事実と、振替や払い戻しのご案内だけ書けば足ります。

**③ 送信前に必ず確認する**

1. 「**送信先と本文を確認**」を押します。**送信件数**と、**実際に届く本文**がそのまま表示されます。
2. 「**まず自分宛に試す**」で、ご自身のアドレスに 1 通送ります。**この 1 通が届くかどうかで、本送信が届くかが分かります。** 届かなければ本送信の前に原因を解消してください。
3. 「**N 件に送信する**」を押します。確認のポップアップが出ます。**送信後は取り消せません。**

**④ 送信状況を見る**

送信はいったんキューに積まれ、順次送られます。急ぐ場合は「メール」メニューの「未送信を今すぐ送る」を使ってください（→ 次章）。

### 文例

```
件名: 【9月12日】台風接近に伴う開催中止のお知らせ

このたびご予約いただいた体験プログラムにつきまして、
台風接近により開催を中止することといたしました。
ご準備いただいたところ誠に申し訳ございません。

振替開催につきましては、日程が決まりしだい改めてご案内いたします。
ご質問は本メールにご返信いただくか、下記までお問い合わせください。

（事務局の連絡先）
```

（体験内容と開催日時は本文の先頭に自動で付くため、上の文に書く必要はありません。）

## 7. メールの管理

「メール」メニュー（事務局のみ）で、送信状況を確認できます。

### 絞り込み

- **状態**: すべて / 未送信 / 送信済み / 失敗
- **種別**: すべて / **個別（予約関連）** / **一斉送信**

種別で分けられるようにしているのは、300 件の一斉送信で、同じ時間に出た予約確定メールが埋もれないようにするためです。
**確定メールは相手が待っているメールなので、そちらを先に確認してください。**

### 「未送信を今すぐ送る」

押すと**200 件ずつ**送ります。押したあと「**送信 200 件、失敗 0 件。残り 1745 件です。**」のように結果が出ます。

- 残りがある間は、もう一度押せば続きを送ります。
- **急がないのであれば、押さずに放置して構いません。** 定期実行で順次送られます。
- **「失敗」が増え始めたら、押すのをやめてください。** 送信先のメールサーバーに受信を拒否されている可能性があります。一斉送信のあとは、とくにここを見てください。

### 「失敗」が出たとき

一覧の件名の下に赤字でエラー内容（`last_error`）が出ます。5 回失敗すると「失敗」状態で止まり、それ以上自動では送られません。
原因を解消してから「**再送**」を押すと、もう一度送信を試みます。

### 送られるメールの種類

| 送るタイミング | 宛先 |
|---|---|
| 予約が確定したとき | ご本人 |
| キャンセル待ちで受け付けたとき | ご本人 |
| キャンセルを受け付けたとき | ご本人 |
| 繰り上げて確定にしたとき | ご本人 |
| キャンセルで空席が出たとき（お待ちの方がいる場合） | 事務局 |
| 一斉送信 | 選んだ対象の申込者 |

## 8. アカウントの管理

「アカウント」メニュー（事務局のみ）。

### 作成

| 項目 | 説明 |
|---|---|
| ユーザー名 | 英数字と `.` `_` `-` のみ。**作成後は変更できません**（操作履歴に記録されるため） |
| 表示名 | 画面右上に出ます（例: 株式会社◯◯ 田中） |
| 種別 | **事務局**（すべて見える）／**会社担当者**（自社のみ） |
| 所属会社 | 種別が「会社担当者」のときは必須 |

**作成すると、画面に初回パスワードが 1 度だけ表示されます。** その場で控えて、ご本人に安全な方法でお伝えください。あとから同じパスワードを表示することはできません（分からなくなったら再発行します）。

### パスワード再発行

一覧の「パスワード再発行」を押すと、新しいパスワードが画面に表示されます。**現在のパスワードは使えなくなります。**
ログインできないという連絡を受けたときは、まずこれで対応してください。

### 有効／無効

無効にすると、**そのアカウントは次の操作から即座に使えなくなります**（ログイン中でも同じです）。
退職・担当交代のときは、削除ではなく**無効化**をお使いください。誰がどの操作をしたかの記録が残ります。

## 9. よくある問い合わせと答え

### 「予約ボタンが出ない・予約できない」と言われた

上から順に確認してください。

1. **受付設定**が停止になっていないか（全体が止まります）
2. その**開催回が「受付終了」**になっていないか
3. その**体験プログラムが「予約不要」**になっていないか
4. **会社と体験プログラムの両方が「公開」**になっているか
5. **対象年齢**の範囲外ではないか（1 人でも範囲外だと受け付けません）
6. **1予約あたりの上限人数**を超えていないか
7. すでに**同じ体験プログラムに予約**されていないか（**1 人 1 体験プログラム 1 予約**です。別の回への重ね予約もできません）
8. 同じ方が**時間帯の重なる別の予約**をお持ちでないか（開催企業が違っても検出します）
9. 前後の予約との**間隔が 15 分以下**ではないか（移動時間の警告。**現在の設定では警告を出すだけで、予約はできます**。**同じ開催企業どうしは移動が発生しないため対象外**です）

### 「満席と出るのに、空いていると聞いた」

キャンセル待ちの方がいる開催回では、空席があっても新規予約はキャンセル待ちになります（→ [5 章](#5-キャンセル待ちの繰り上げ)）。
その席はお待ちの方のものですので、**繰り上げ**で対応してください。

### 「予約完了メールが届かない」

1. 「メール」メニューでそのアドレスを探し、**状態**を確認します。
   - **未送信** … まだ送られていません。「未送信を今すぐ送る」で送れます。
   - **失敗** … エラー内容を確認してください。アドレスの打ち間違いが多くあります。
   - **送信済み** … システムからは出ています。迷惑メールフォルダのご確認と、ドメイン受信許可をご案内してください。
2. アドレスが間違っていた場合、正しいアドレスで予約を取り直していただくのが確実です。

### 「キャンセルしたい」と電話が来た

ご本人の予約完了メールの URL からキャンセルしていただくのが基本です。
メールが見つからない場合は、予約一覧で氏名やメールアドレスから探し、事務局側でキャンセルしてください（**取り消せません**のでご注意ください）。

### 「何名まで申し込めますか」

体験プログラムごとの「1予約あたりの上限人数」（既定 20 名）までです。それを超える団体は、複数回に分けるのではなく事務局にご相談いただく運用をおすすめします（同じ方の重ね予約はできないためです）。

## 10. とくにご注意いただきたいこと

- **キャンセルと削除は取り消せません。** 確認のポップアップが出ますので、必ず内容を読んでください。
- **一斉送信は取り消せません。** 必ず「送信先と本文を確認」→「自分宛にテスト送信」→ 本送信の順に進めてください。とくに**対象の選び間違い**（全申込者 / 体験プログラム / 開催回）にご注意ください。
- **一斉送信のあとは「メール」メニューの「失敗」を確認してください。** 受信拒否は失敗として記録されます。
- **空席は自動で繰り上がりません。** ダッシュボードの「繰り上げ候補のある開催回」を毎日ご確認ください。
- **パスワードは画面に 1 度だけ表示されます。** その場で控えてください。
- **担当者が変わったらアカウントを無効化**してください（削除より無効化を推奨します）。
- **日時はすべて日本時間**です。
